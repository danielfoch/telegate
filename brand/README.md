# Telegate mark

A phone with a soundwave, an outbound arrow, and a check bubble: you say it, it leaves the phone, it gets done.

- `telegate-mark.svg` — mint (#adf28f) on transparent, ink (#14212a) tick. Use on dark grounds.
- `telegate-mark-ink.svg` — ink on transparent, paper (#f5f7f0) tick. Use on light grounds.

App icons are generated from `telegate-mark.svg` by `swift scripts/make-icons.swift .` — a full-bleed ink square without an alpha channel for iOS, and a rounded, padded icon for macOS. Regenerate after editing the SVG; do not hand-edit the PNGs.
